# 预设模型演示指南

快速体验 Web Wind Tunnel Lab 的预设演示模型。

## 🚀 快速开始

### 1. 启动应用

```bash
npm run dev
```

访问 http://localhost:3000

### 2. 进入风洞实验室

- 点击首页"新建试验"按钮
- 或直接访问 http://localhost:3000/lab

### 3. 加载预设模型

在左侧面板中：

1. 点击"模型"标签
2. 默认显示"预设模型"选项卡
3. 浏览 6 个预设模型
4. 点击"加载模型"按钮

## 📦 预设模型一览

### 🛩️ NACA 0012 翼型

**适合场景**: 学习翼型气动特性  
**推荐参数**:
- 入口速度: 10-50 m/s
- 网格分辨率: 256³
- 湍流模型: SST k-ω

**观察要点**:
- 上表面流速加快（伯努利原理）
- 前缘驻点
- 后缘尾迹

---

### ⭕ 圆柱体

**适合场景**: 理解卡门涡街  
**推荐参数**:
- 入口速度: 0.1-10 m/s
- 网格分辨率: 128³
- 湍流模型: LES Smagorinsky

**观察要点**:
- 交替脱落的涡
- 涡街频率
- 阻力系数变化

**经典现象**:
```
Re < 47: 稳定流动，无涡脱落
47 < Re < 200: 层流涡街
Re > 200: 湍流涡街
```

---

### ⚽ 球体

**适合场景**: 体验三维效应  
**推荐参数**:
- 入口速度: 0.1-10 m/s
- 网格分辨率: 128³
- 湍流模型: k-ε

**观察要点**:
- 三维分离
- 尾流结构
- 阻力危机

---

### 🚗 简化汽车

**适合场景**: 汽车空气动力学入门  
**推荐参数**:
- 入口速度: 20-50 m/s (72-180 km/h)
- 网格分辨率: 256³
- 湍流模型: SST k-ω

**观察要点**:
- 车头正压区
- 车顶负压区
- 车尾尾流

**优化方向**:
- 降低 Cd → 提高燃油效率
- 降低 Cl → 提高高速稳定性

---

### ✈️ 简化飞机

**适合场景**: 飞机气动分析  
**推荐参数**:
- 入口速度: 50-100 m/s (180-360 km/h)
- 网格分辨率: 256³
- 湍流模型: SST k-ω

**观察要点**:
- 机翼上表面低压
- 机翼下表面高压
- 翼尖涡

**性能指标**:
- 升阻比 (L/D): 越大越好
- 巡航效率

---

### 🏎️ Ahmed 车体

**适合场景**: 研究汽车尾流结构  
**推荐参数**:
- 入口速度: 40-60 m/s
- 网格分辨率: 256³
- 湍流模型: LES Smagorinsky

**观察要点**:
- 斜背面分离泡
- C 柱涡
- 尾流回流区

**研究价值**:
- 国际标准验证模型
- 大量实验数据可对比
- 湍流模型验证

## 🎓 教学演示流程

### 演示 1: 伯努利原理（NACA 0012）

1. 加载 NACA 0012 翼型
2. 设置攻角 5°
3. 启动仿真
4. 观察上表面速度加快（蓝色→红色）
5. 解释压力降低 → 产生升力

### 演示 2: 卡门涡街（圆柱体）

1. 加载圆柱体
2. 设置低风速（1 m/s）
3. 启动仿真
4. 观察交替脱落的涡
5. 测量涡脱落频率

### 演示 3: 汽车风阻（简化汽车）

1. 加载简化汽车
2. 设置高速（50 m/s）
3. 启动仿真
4. 观察车头正压区和车尾尾流
5. 讨论如何降低风阻

### 演示 4: 分离流动（Ahmed 车体）

1. 加载 Ahmed 车体
2. 设置中等风速（40 m/s）
3. 启动仿真
4. 观察斜背面分离
5. 分析 C 柱涡结构

## 🔬 实验对比

### 实验 1: 雷诺数效应（圆柱体）

| 实验 | 风速 | 雷诺数 | 预期 Cd | 观察现象 |
|------|------|--------|---------|---------|
| 1 | 0.5 m/s | 3.5×10⁴ | 1.2 | 层流涡街 |
| 2 | 5 m/s | 3.5×10⁵ | 0.3 | 阻力危机 |
| 3 | 10 m/s | 7×10⁵ | 0.7 | 湍流涡街 |

### 实验 2: 攻角效应（NACA 0012）

| 实验 | 攻角 | 预期 Cl | 预期 Cd | 观察现象 |
|------|------|---------|---------|---------|
| 1 | 0° | 0.0 | 0.006 | 对称流动 |
| 2 | 5° | 0.6 | 0.010 | 产生升力 |
| 3 | 15° | 1.2 | 0.025 | 接近失速 |

### 实验 3: 湍流模型对比（Ahmed 车体）

| 实验 | 湍流模型 | 预期 Cd | 计算时间 | 精度 |
|------|---------|---------|---------|------|
| 1 | k-ε | 0.30 | 快 | 中等 |
| 2 | SST k-ω | 0.28 | 中等 | 高 |
| 3 | LES | 0.29 | 慢 | 最高 |

## 📊 数据分析

### 升力系数曲线

1. 运行 NACA 0012 仿真
2. 观察右侧面板"升力系数"曲线
3. 等待收敛（曲线平稳）
4. 记录最终 Cl 值

### 阻力系数对比

1. 分别加载不同模型
2. 使用相同风速（如 10 m/s）
3. 对比 Cd 值
4. 分析形状对阻力的影响

### 流场可视化

1. 切换可视化模式（速度/压力/涡量）
2. 使用切片功能查看截面
3. 启用流线显示
4. 截图保存结果

## 🎯 练习题目

### 高级
1. 验证湍流模型对 Ahmed 车体尾流的预测精度
2. 研究网格分辨率对结果的影响
3. 对比 LES 和 RANS 模型的差异

## 💡 提示与技巧

### 提高仿真速度
- 降低网格分辨率（128³ → 64³）
- 增大时间步长
- 使用 k-ε 模型而非 LES

### 提高精度
- 增加网格分辨率（128³ → 256³）
- 减小时间步长
- 使用 SST k-ω 或 LES 模型

### 可视化技巧
- 使用切片查看内部流场
- 启用流线追踪粒子轨迹
- 调整颜色映射范围
- 使用等值面显示特定值

## 🐛 常见问题

### Q: 预设模型加载失败？
A: 检查浏览器控制台，确保 WebGPU 已启用。

### Q: 仿真结果不合理？
A: 检查参数设置，特别是风速和网格分辨率。

### Q: 无法观察到涡街？
A: 降低风速，增加仿真时间，使用 LES 模型。

### Q: 阻力系数偏差大？
A: 检查参考面积设置，增加网格分辨率。
